# Changelog

## 0.2.0 — 2026-09-08

First GitHub release of Margin Dictionary.

- Select a word and open its Cambridge English definitions in a page popup.
- Read examples, parts of speech, UK/US IPA and pronunciation audio.
- Open the dictionary from the page's right-click menu, with selected-word lookup.
- Search manually from the toolbar or use Alt+Shift+D on a selection.
- Handle small windows, long entries, unavailable words and network errors.
- Use an opaque ivory/sage surface for readability in Firefox and Zen.
- Add Mozilla publishing instructions, privacy policy and automated CI.

The XPI is unsigned. Use temporary installation for development; permanent
installation requires Mozilla signing.
